# SHRESTHA // PORTFOLIO

My personal portfolio - a neon cyberpunk cinematic experience, built as ONE self-contained HTML file.
No frameworks. No build step. No external assets - every image, sound and voice clip is embedded.

Live site: https://iamshresthaxcoder.github.io/

## What's inside

- ENTER gate -> 15s cinematic intro: black hole -> TV glitch -> phonk fire reveal of WELCOME TO SHRESTHA'S SPACE
- Voice greeter: an "incoming transmission" panel that drops in, with my own recorded voice
- Interactive galaxy background - 5 spiral galaxies, parallax, make-a-wish shooting stars
- Holographic 3D tilt project cards + HUD targeting brackets
- MyDaksha chat assistant
- HYPERSPACE warp, Konami code easter eggs (matrix rain / gravity mode), supernova
- PWA installable, share buttons, desktop-by-default on phones

## Run it

Just open `index.html`. Everything is embedded. Audio starts after the ENTER click
(browser autoplay rules - the gate is the on switch).
